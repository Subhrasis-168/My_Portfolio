# Subhrasis Biswal – Personal Portfolio Website 🌐

This is my personal portfolio website built using HTML, CSS, JavaScript, and animation libraries. It showcases my technical skills, education, resume, certifications, contact details, and real-world projects.

## 🔗 Live Portfolio
👉 [Visit My Portfolio](https://subhrasis-portfolio.vercel.app/)  
👉 [View My Resume](https://resume-subhrasis.vercel.app/)

## 📌 Features
- Responsive design with smooth animations
- "About Me" section with personal and technical info
- Resume timeline (Education + Internship)
- Projects section with GitHub repo links and images
- Resume link (hosted via Vercel)
- Contact section with email, phone, and social profiles
- Built using Bootstrap-based layout and animation libraries

## 💼 Tech Stack
- **Languages**: HTML, CSS, JavaScript
- **Libraries**: Owl Carousel, AOS, Font Awesome, Bootstrap
- **Hosting**: [Vercel](https://vercel.com/)
